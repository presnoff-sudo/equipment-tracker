Настройки

Распознавание по фото
Распознавание типа и размеров оборудования по фото выполняется через Anthropic API (Claude с поддержкой изображений). Ключ хранится только на этом устройстве и никуда, кроме api.anthropic.com, не отправляется. Получить ключ можно на console.anthropic.com. Запросы к API оплачиваются с вашего аккаунта.
Каталог
В приложение встроен каталог оборудования ИТАБ (F50): — позиций с заводскими номерами, распознанных из PDF. Часть названий может быть неполной — при необходимости поправьте вручную.
